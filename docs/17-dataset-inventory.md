## Как использовать инвентаризацию

1. Сначала короткие динамические bag для интеграции; стоячий короткий bag подтверждает только чтение/старт.
2. Для accuracy выбирать записи с непустым GNSS и затем проверять покрытие и качество на каждом интервале.
3. Для no-GNSS runtime использовать 35 записей без эталона; фактическая ошибка на них недоступна.
4. Делить train/validation/test целыми сессиями с проверкой пересечений временных диапазонов, а не только по случайному bag ID.
5. Запускать каждый bag в новой эпохе состояния; их суммарная длительность не является одним непрерывным маршрутом.
