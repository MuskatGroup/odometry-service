# Допущения и ограничения

## Входы и объект

- Входные `/vehicle/*_bogie_velocity` содержат км/ч; `/result/velocity` содержит м/с.
- Позиция контроллера лежит в `[-15,15]` и нормализуется делением на 15.
- Движение моделируется вдоль одного направленного Pathgraph без перевода стрелки внутри
  активной оценки.
- `base_link` находится на оси передней тележки; база тележек — 7,55 м.
- Master соответствует антенне `[-9.873,0,3]`, rover — `[2.563,0,3]` в `base_link`.
- Map использует continuous MGRS относительно `37UCB`: modulo 100 км не применяется.
- Геоидная поправка не выполняется; z использует высоту, предоставленную GNSS/Pathgraph.
- В strict-режиме GNSS отсутствует, а направленный `route_id` и `s0` задаются при запуске.
- GNSS не считается истинной скоростью. Он используется для разрешённой коррекции и
  построения offline reference с указанием coverage.
- Route после инициализации фиксирован. Несогласованный GNSS отклоняется.
- Reverse motion не поддерживается текущим состоянием `v>=0`.
- Runtime не выполняет идентификацию параметров и не содержит онлайн-ML.
- При недоступной абсолютной позиции скорость может публиковаться, но валидный
  `/result/position` не публикуется.
- При выходе за Pathgraph публикуется `OUT_OF_GRAPH`; крайняя точка не подставляется.

## Статистические и эксплуатационные ограничения

- Параметры идентифицированы по предоставленной линии и двум трамваям; перенос на другую
  линию, сезон или существенно иную загрузку требует повторной проверки.
- Погода, масса, износ колёс, сопротивление и сцепление не наблюдаемы по отдельности по
  трём обязательным входам. Они входят в таблицы привода и суммарное возмущение `d`.
- Два одинаково ошибочных колесных канала могут выглядеть согласованными. Model innovation
  уменьшает риск, но не гарантирует обнаружение общего проскальзывания.
- Covariance и пороги являются инженерной оценкой, а не доказанной вероятностью ошибки.
- При длительной потере обоих колёс ошибка model-only прогноза неограниченно накапливается;
  после `max_model_only_s` результат помечается недействительным.
- Решение оценивает движение по направлению маршрута и не решает глобальную локализацию вне
  выданного Pathgraph.
- ПО является прототипом хакатона и до независимой валидации не должно использоваться как
  единственный источник для управления реальным транспортом.
