# Допущения и ограничения

## Входы и объект

- Входные `/vehicle/*_bogie_velocity` содержат км/ч; `/result/velocity` содержит м/с.
- Позиция контроллера лежит в `[-15,15]` и нормализуется делением на 15.
- Движение моделируется вдоль одного направленного Pathgraph без перевода стрелки внутри
  активной оценки.
- `base_link` находится на оси передней тележки; база тележек — 7,55 м.
- Master соответствует антенне `[-9.873,0,3]`, rover — `[2.563,0,3]` в `base_link`.
- Map использует continuous MGRS относительно `37UCB`: modulo 100 км не применяется.
- Геоидная поправка не выполняется; z использует высоту, предоставленную GNSS/Pathgraph.
- В strict-режиме GNSS отсутствует. Для карты направленный `route_id` и `s0` задаются
  при запуске; без них доступна только относительная along-track одометрия.
- GNSS не считается истинной скоростью. Он используется для разрешённой коррекции и
  построения offline reference с указанием coverage.
- Route после инициализации фиксирован. Несогласованный GNSS отклоняется.
- Reverse motion не поддерживается текущим состоянием `v>=0`.
- Runtime не выполняет идентификацию параметров и не содержит онлайн-ML.
- Оба обязательных выхода публикуются при наличии конечной оценки, включая интервалы
  после `max_model_only_s`. Ненадёжность обозначается `/odometry/estimate.valid=false`,
  covariance и диагностикой. У `nav_msgs/Odometry` собственного флага valid нет.
- Без привязки публикуется `frame=odom`, x — путь от старта; вне известной карты —
  `frame=track/<route>`, x — along-track координата. Это не глобальная XY-позиция.
  Для checker, игнорирующего frame, нужна начальная привязка из [JURY.md](JURY.md).
  Совместимый счётчик `position_withheld_horizon_count` теперь равен нулю.
- Скорость (`/result/velocity`) публикуется независимо от состояния позиции, в том числе в
  `MODEL_ONLY_HORIZON`, — единственный сигнал о её ненадёжности передаётся через
  `/odometry/estimate.valid=false` и коды причин.
- При выходе за Pathgraph публикуется `OUT_OF_GRAPH`; крайняя точка не подставляется.
- Автоматический старт скорости опирается на первую пригодную группу колёс. Если оба
  канала уже ошибочны в момент запуска, истинная начальная скорость не наблюдаема;
  для известного старта следует задать `initial_v_mps` явно.
- `initialization_only` ограничен первыми 5 секундами входного потока или первой принятой
  привязкой. Если весь этот участок вне карты, абсолютная привязка не появится.

## Статистические и эксплуатационные ограничения

- Параметры идентифицированы по предоставленной линии и двум трамваям; перенос на другую
  линию, сезон или существенно иную загрузку требует повторной проверки.
- Погода, масса, износ колёс, сопротивление и сцепление не наблюдаемы по отдельности по
  трём обязательным входам. Они входят в таблицы привода и суммарное возмущение `d`.
- Два одинаково ошибочных колесных канала могут выглядеть согласованными. Model innovation
  уменьшает риск, но не гарантирует обнаружение общего проскальзывания.
- Подтверждённое залипание ненулевой скорости сохраняется до изменения показаний.
  Нулевые показания могут восстановиться при остановке, согласованной с моделью.
  Точное повторение не обнаруживает медленно меняющийся общий bias/slip; при слабом
  ожидаемом ускорении залипание также может остаться нераспознанным.
- Covariance и пороги являются инженерной оценкой, а не доказанной вероятностью ошибки.
- При длительной потере обоих колёс ошибка model-only прогноза неограниченно накапливается;
  после `max_model_only_s` результат помечается недействительным.
- Решение оценивает движение по направлению маршрута и не решает глобальную локализацию вне
  выданного Pathgraph.
- Header-time offline-прогон не моделирует DDS-задержки. Он использует явно заданные s0/v0
  по GNSS в начале выбранного окна; режим `never` запрещает дальнейшие коррекции, но
  не означает холодный старт без начальных условий.
- Лабораторный `initial` разрешает коррекции 10 секунд; это исследовательский режим,
  не точная имитация ROS-политики `initialization_only` (до первой привязки, максимум 5 секунд).
- ПО является прототипом хакатона и до независимой валидации не должно использоваться как
  единственный источник для управления реальным транспортом.
