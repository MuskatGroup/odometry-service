# Исправление восстановления после залипания — 27.09.2026

Продолжение [проверки runtime](RUNTIME_VALIDATION.md), та же ветка
`fix/runtime-validation`. Числа ниже сравнивают две версии **одного и того же
исправленного лабораторного pipeline**, а не старый неполный загрузчик с новым.
Таблицы привода, шумы и численные пороги не переобучались и не менялись.

## Причина и изменение

Раньше `frozen` зависел от текущей команды контроллера. При переходе к выбегу канал
мог стать `normal`, хотя показания не изменились. После длительного отказа путь
reacquisition снова принимал это значение и искажал скорость и возмущение `d`.

Теперь подтверждённое залипание сохраняется до изменения показаний. Далее действуют
обычные innovation/derivative gates и гистерезис восстановления. Для нулевых показаний
есть исключение: восстановление допускается, если модель тоже остановилась и команда
не требует положительного ускорения. Остановка под тормозом не требует вращения колёс.

Первая промежуточная версия слишком долго удерживала отказ на стоянке после короткой
команды тяги. Это обнаружено на validation, исправлено до финального test-прогона и
закреплено отдельным regression-тестом. Промежуточный отчёт `after/` не финальный;
для validation используется только `final/`.

Это не независимый диагностический наблюдатель и не решение проблемы наблюдаемости.
Общий плавный slip, общий scale bias и незаметное залипание при слабом ожидаемом
ускорении остаются ограничениями. Гипотеза остановки тоже опирается на модель.

GNSS-derived scorer использует интерполяцию по header stamps, без экстраполяции и
с допустимым разрывом reference до 0,5 с. Для пути учитываются только map-frame
выходы (5788 пар). Чистые ROS-ошибки практически те же, что до изменения
(0,02336 м/с и 0,3393 м); по этому прогону улучшение точности не заявляется.
Набор времён публикаций зависит от планировщика, это не детерминированная offline-пара.

Пиковая задержка превысила целевые 100 мс, но осталась ниже допуска 250 мс.
Показатель не включает задержку до callback. Это один замер с параллельным offline
benchmark, а не гарантия hard real-time. Полный 22-минутный check-bag после этой
правки **не повторялся**; его предыдущие результаты сохранены отдельно.
Артефакты: `artifacts/freeze-validation/ros-moving/{report.json,gnss-metrics.json}`.

## Воспроизведение

```bash
uv run python -m odometry_lab.cli real-benchmark \
  --output artifacts/my-freeze-validation --subset validation \
  --model-profile configs/models/default.yaml --preset M1-cal --gnss-mode never

uv run python tools/compare_benchmarks.py \
  artifacts/freeze-validation/before/real-benchmark.json \
  artifacts/freeze-validation/final/real-benchmark.json

uv run python -m odometry_lab.cli real-benchmark \
  --output artifacts/my-freeze-test --subset test \
  --model-profile configs/models/default.yaml --preset B0 --preset M1-cal --gnss-mode never
uv run python tools/compare_benchmarks.py \
  artifacts/runtime-validation/lab-test/real-benchmark.json \
  artifacts/freeze-validation/test/real-benchmark.json

docker compose --profile reserve build reserve
docker run --rm --cpus 2 --memory 512m -e RUN_ROS_TESTS=1 -e ROS_DOMAIN_ID=76 \
  odometry-ros:validation /usr/bin/python3 -m pytest -q \
  tests/integration tests/test_adaptive.py tests/test_fixed_lag.py
docker compose --profile reserve run --rm reserve /usr/bin/python3 /tools/validate_rosbag.py \
  --bag /bags/30618_2050d396 --output /artifacts/my-freeze-ros \
  --start-offset 784.24469272 --duration 120 --gnss-policy initialization_only
docker compose --profile reserve run --rm reserve /usr/bin/python3 /tools/score_gnss_reference.py \
  --directory /artifacts/my-freeze-ros --reference /reference/reference/30618_2050d396.csv \
  --route-id tallinskaya-shchukinskaya
```

Первую команду нужно выполнять в соответствующей версии кода для каждого из двух
отчётов. `compare_benchmarks.py` отказывается сравнивать разные составы bag/scenario/
preset/GNSS и длины окон, показывает неполные пары как недоступные, не подставляет нули.
Он не доказывает совпадение исходных bag/эталона: для этого сохраняются происхождение
и условия эксперимента. Большие локальные artifacts не включены в git.
