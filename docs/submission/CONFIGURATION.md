# Допущения, ограничения и конфигурация

## Допущения

- Трамвай движется вперёд; задний ход не поддерживается.
- Входные скорости тележек заданы в км/ч, выходная скорость — в м/с.
- `base_link` находится на оси поворота передней тележки на уровне головки рельса;
  расстояние до задней тележки — 7,55 м.
- Смещения GNSS-антенн относительно `base_link`: master `[-9.873, 0, 3]` м,
  rover `[2.563, 0, 3]` м.
- Абсолютная позиция требует известного `route_id/s0` либо успешной начальной GNSS-привязки.
- Погода, масса, износ, сцепление и отдельные сопротивления не наблюдаемы независимо
  по трём обязательным входам. Их совместное влияние входит в drive map и disturbance.
- Covariance используется как диагностическая оценка и не является сертифицированной.

Номинальная пустая масса трамвая — 27 500 кг. В текущем фильтре она не является
отдельным параметром: таблицы хранят ускорение, то есть уже нормированную на эффективную
массу силу. Эффективный радиус колеса и передаточное число также поглощены таблицей.

## Runtime-параметры

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `vehicle_id` | `default` | выбор `configs/models/<id>.yaml`, иначе `default.yaml` |
| `route_id` | пусто | фиксированное направление Pathgraph |
| `s0` | `0` м | начальная along-track координата |
| `initial_v_mps` | `-1` | `-1`: взять первое согласованное колесо; иначе явная стартовая скорость |
| `gnss_policy` | `disabled` | `disabled`, `initialization_only`, `intermittent` |
| `gnss_initialization_window_s` | `5` с | максимальное окно начальной привязки |
| `publish_rate_hz` | `50` Гц | частота публикации, минимум 10 Гц |
| `processing_delay_ms` | `300` мс | fixed-lag окно для задержанных Header stamps |
| `max_model_only_s` | `10` с | горизонт валидного прогноза без колёс |
| `gnss_sync_tolerance_ms` | `200` мс | синхронизация двух антенн |
| `gnss_cross_track_gate_m` | `8` м | геометрический gate относительно пути |
| `gnss_baseline_error_gate_m` | `1` м | gate длины GNSS-базы |
| `gnss_position_variance_m2` | `4` | дисперсия GNSS-position update |
| `gnss_velocity_variance_m2ps2` | `0.25` | дисперсия GNSS-speed update |
| `cross_track_variance_m2` | `4` | поперечная covariance Odometry |
| `yaw_variance_rad2` | `0.04` | yaw covariance Odometry |

## Параметры модели

Versioned YAML-профили находятся в [`configs/models`](../../configs/models).
Загрузчик запрещает неизвестные поля и неверные размеры таблиц.

| Раздел | Основные параметры |
|---|---|
| `longitudinal` | `tau_s`, `c1_inv_s`, `c2_inv_m`, предел disturbance |
| `traction`, `braking` | оси `controller_u`, `speed_mps`, матрица `acceleration_mps2` |
| `noise` | process noise `q_v/q_a/q_d`, floor дисперсии колеса |
| `wheel_health` | NIS gates, предел производной, freeze/reacquisition и hysteresis |

## Известные ограничения

- Общий синфазный slip/slide двух тележек слабонаблюдаем без независимого датчика.
- Ошибка `route_id/s0` превращается в постоянную абсолютную ошибку позиции.
- За пределами предоставленного Pathgraph валидная MGRS-позиция не публикуется.
- Маршрут после привязки не переключается автоматически.
- Нода оценивает эквивалентное ускорение привода, но не выдаёт отдельно момент двигателя,
  массу, коэффициент сцепления или радиус колеса.
- При одновременном отказе обоих колёс точность ограничена качеством drive map и горизонтом
  `max_model_only_s`.
