# Навигация по документации

Дата актуализации: 26 сентября 2026.

Этот файл — единственная точка входа в документацию проекта. Документы не удаляются,
поскольку содержат историю решений и результаты исследований, но не все из них задают
текущие требования.

## Что читать второму участнику

Обязательно прочитать только:

1. [`23-parallel-implementation-handoff.md`](23-parallel-implementation-handoff.md) —
   текущий план, зона владения, публичный API и критерии приёмки.

Для потока B достаточно разделов 1–4, 6–9 этого документа. Если задача реализуется без
неясностей, остальные Markdown-файлы читать не требуется.

Открывать адресно только при необходимости:

- [`19-pathgraph-audit-and-integration.md`](19-pathgraph-audit-and-integration.md) —
  фактическая структура выданных JSON Pathgraph;
- [`21-coordinate-frame-and-gnss-extrinsics.md`](21-coordinate-frame-and-gnss-extrinsics.md) —
  вывод формул MGRS и смещений антенн;
- [`17-dataset-inventory.md`](17-dataset-inventory.md) — состав rosbag и наличие топиков;
- [`16-dataset-getting-started.md`](16-dataset-getting-started.md) — локальные инструменты
  чтения и анализа `.db3`.

При противоречии всегда действует `23-parallel-implementation-handoff.md`. Не нужно
самостоятельно объединять требования из старых документов.

## Архив подготовки проекта

Документы 01–12 относятся к этапам формирования заявки, выбора архитектуры и создания
первого каркаса:

- 01–06 — первоначальная гипотеза, архитектура, контракты и вопросы;
- 07–08 и 11 — тексты командной заявки;
- 09–10 — первоначальный план старта без выданного датасета;
- 12 — раннее разделение компонентов и репозитория.

Они сохраняются ради истории и презентационных материалов. Для реализации новых задач
их читать не нужно.

## Как менять принятые решения

1. Обсудить изменение в команде.
2. Сначала обновить документ 23 и его публичные контракты.
3. При необходимости обновить профильный справочный документ.
4. Добавить тест, подтверждающий новое решение.
5. Не превращать старый план в параллельное техническое задание.
